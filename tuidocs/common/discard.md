# Discard the changes

You left a form that holds changes you have not saved. This question asks whether to throw them away. The question names no value.

- {yes} discards the form. The changes are lost.
- {no} keeps the form open so you can go on editing or save it with {save}.

{enter} takes the default, which is to keep the form.
