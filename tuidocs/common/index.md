# Shared dialogs

Several areas open the same questions, forms and results. Their pages are collected here.

- Stack actions: the question, the update preview and the result of an action on stacks or containers.
- Service log: the output of a container, of a stack and of the deploy service.
- Rollback: going back to the state before an update run.
- sudo: the question to read as root, the plan of a change with the exact command, and its result.
- Files: the forms to create, rename and copy an entry, the editor questions and the secrets question.
- Forms: discarding changes and the result of a setting.

Nothing runs before you answer. {no} cancels every question, and {enter} takes the answer marked as the default, which is always the harmless one.
