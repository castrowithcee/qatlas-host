# Ergebnis einer Einstellung

Dieser Dialog meldet, dass eine Einstellung geändert wurde, mit den Einzelheiten dazu, was getan wurde, etwa den Branch, den Head-Commit oder die Zahl der Dateien. Eine Änderung ohne Einzelheiten zeigt ihre Meldung stattdessen nur in der Meldezeile.

{no} und {enter} schließen den Dialog. Das Formular, das die Änderung gemacht hat, wird mit ihm geschlossen, und die Listen dahinter werden neu gelesen.
