# Restore a backup

{restore} opens a list of the backups of the stack with their creation time and size. The newest backup and incomplete ones are not offered. Without an older backup a message says so. Choosing a backup opens the question for it.

- {yes} stops the stack, overwrites its current data with the backup and starts the stack again. This cannot be undone.
- {no} or {enter} cancels and changes nothing.
- In the list, {enter} chooses, {back} leaves it without a change.
