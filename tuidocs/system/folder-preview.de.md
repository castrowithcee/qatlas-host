# Dateivorschau

Die Vorschau zeigt eine Textdatei nur lesend, nach ihrem Format gefärbt. Eine binäre oder sehr große Datei, ein Link und alles, was keine reguläre Datei ist, zeigen statt des Textes einen Hinweis. Eine Datei, die nur root lesen kann, wird nach einer Rückfrage mit sudo gelesen.

- {up}, {down}, {pageup}, {pagedown}, {first} und {last} blättern.
- {search} startet eine Suche, {enter} behält sie, {back} leert sie. {log.next} und {log.prev} springen zwischen den Treffern.
- {log.wrap} bricht lange Zeilen um.
- {text.numbers} schaltet die Zeilennummern um.
- {text.reveal} deckt Werte auf, die die Vorschau verbirgt, etwa Geheimnisse, und verbirgt sie wieder.
- {edit} bearbeitet die Datei in deinem Editor.
- {reload} liest die Datei neu.
- {back} schließt die Vorschau und kehrt zum Ordner zurück.
