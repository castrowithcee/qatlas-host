# Stacks

The Stacks area lists the stacks of the host under the stack folders they live in. A stack folder is a folder with Compose files that qhost deploys from, either a clone of a git repository or a local repository.

- The list shows each folder with its stacks and lets you add, fetch and release folders.
- Adding a folder is a short series of questions. Nothing changes before the last one.
- A folder with a remote needs a deploy key that you enter on the git platform.
- The deploy service rolls the stacks out. It must be set up before the area has content.
