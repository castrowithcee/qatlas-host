# Welcome

The interface has one area for each job. Switch between them with {area}, or type {command} and the name of an area.

- Stacks lists the stacks of the host and runs actions on them.
- Stack detail, Runs, Settings, Containers, Proposals and System follow.

Press {help} or {help.f9} on any screen to read about it. {help.f9} also works inside a text field, where the question mark is typed as a character. The overview opens with {help.outline} and the search with {search}. Back closes the help and returns to the screen you left.
