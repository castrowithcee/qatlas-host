# Settings

Settings has one tab for each job: General, Credentials, Maintenance window, Notifications and Webhooks. The tab line is focused when you arrive. Step between the tabs with {left} and {right}, and move into the page of a tab with {next}.

- General holds the preferences of this interface.
- Credentials stores the logins qhost uses for registries and GitHub.
- Maintenance window sets when deploy services may update.
- Notifications adds channels that report events.
- Webhooks sets up the receiver that lets a call check a stack at once.

Every change to the host asks first. {yes} confirms and {no} cancels, and {enter} gives the default answer, which is Cancel. When the change needs root, a further question follows before it runs. A secret you type is never shown again.

{reload} reads the page again. {back} leaves the form or the page you are on.
